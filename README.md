# SmartDelivery Router - Sistema de Planificación de Rutas Urbanas

Simulador interactivo y motor de cálculo de rutas óptimas para logística. Este proyecto forma parte de mi portafolio profesional de desarrollo de software.


## Problemática que Resuelve

En el transporte y despacho de pedidos, los transportistas enfrentan bloqueos viales constantes: calles cerradas por mantenimiento, accidentes imprevistos o congestión vehicular. Las decisiones basadas en intuición o aproximaciones no verificadas provocan retrasos en entregas y sobrecostos operativos.

**SmartDelivery Router** aborda esta necesidad al proporcionar:
1. **Representación Espacial:** Modela el plano urbano como una red de intersecciones y tramos transitables.
2. **Restricciones en Tiempo Real:** Permite simular cierres viales dinámicos que inhabilitan tramos de la ciudad.
3. **Cálculo de Distancia Mínima:** Garantiza matemáticamente la ruta más corta y viable desde el centro de distribución hasta el destino del cliente, evitando zonas bloqueadas.
4. **Auditoría Visual:** Ofrece una visualización interactiva del camino óptimo y de las zonas exploradas durante la resolución, aportando transparencia operativa.
